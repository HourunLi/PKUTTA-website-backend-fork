# `README.md`

项目操作入口文档，说明环境与启动、唯一实时 JSON 数据库、CSV 规范、弃权录分、小组积分与比值排名、持久化排名抽签、淘汰赛分区抽签及出线级别、小组时间桌号裁判的单向同步、三表布局、手机居中和叶子编号。独立淘汰赛 CSV 接受 `-1`，启动升级按新小组排名同步旧出线元数据，同人选保留签表比分、换人选清空待重抽。创建赛事可选自定义文件名，输入始终显示且仅勾选后启用，重复名不覆盖。顶部品牌和 favicon 使用供应的 JPEG，固定顶栏预留内容高度；进入赛事后可以搜索各项目阶段中的成员相关场次。说明分块加载、60 秒内存缓存、并发去重、保存失效和旧请求保护，以及搜索部分失败保留已有结果。Submit 位于右下角，在 `webpage/` 仓库后台执行固定 Git 命令，输出终端，运行中禁用、失败弹窗、成功安静；发布无需构建。测试命令包括 Python 测试与四套 Node 前端检查。
