# `tests/test_revision8_storage.py`

验证修订八的独立循环赛排名持久化。测试在 `tmp/tests/` 下创建自动清理的临时数据库，使用公开的 `Database` 创建与保存入口，不修改真实赛事。

九项测试覆盖：

- 未全部完赛时排名为空，以及原选手与场次顺序不变。
- 排名直接复用小组积分与胜负比算法，使用能区别于旧循环赛总局数、总得分规则的赛果。
- 最终同分抽签顺序跨场次信息编辑、数据库重启、撤销完赛与再次完赛保持固定。
- 添加、编辑、删除局比分后及时重算排名，删至胜负不明时清空排名。
- 单方/双方 `wo` 的积分、按零计算的比值，以及未参加比较者的空依据字段。
- 旧循环赛 JSON 启动升级，保存排名且完整保留原比分、选手顺序、场次顺序与裁判/时间/桌号。
- 场次缺失、重复对阵、非法索引不被误判为全部完赛。
- 修复非法历史抽签排列而保留比赛数据。
- 单名选手、零场次循环赛的完整名次。

运行：`python -B -m unittest tests.test_revision8_storage -v`。
