# `tests/test_workflow.py`

使用 Python 标准库 `unittest` 验证种子小组抽签、独立循环赛的 revision 4 并列排名、轮空传播、赛事和项目创建、比分及出线流程，以及实时 JSON 与匹配文档保存。中文姓名“张3”在抽签后保持原样，含替换字符 `�` 的 CSV 被拒绝且不会创建项目。小组出线使用保存的积分排名；排名改变而出线名单不变时保留已有淘汰赛签表，并更新第一名正种子、其他第一名 `0`、其余 `-1` 的级别分类。

铜牌赛测试覆盖：主赛已完但铜牌未完时不产生结果；完赛后冠亚季殿军与字典序并列第五名正确；半决赛改变时清除失效的铜牌、决赛比分；三人签表轮空可自动决定第三名。旧 JSON 测试验证兼容读取、初始化升级及铜牌录分保留已有主赛比分。

空比分测试覆盖添加、补录、清空、删局、非法分数拒绝、只有普通不完整局时不能结束，以及修改后的排名和晋级变化。保存场次信息删除普通未完整临时局，并校验结束状态。弃权、持久化排名抽签及裁判的专项验证在 `test_revision6_logic.py`、`test_revision6_storage.py`。

实时数据库测试验证数据只存于 `webpage/database/`，后台修改后对应文件立即可读，没有赛事、项目的重复汇总索引。兼容 `build_site()` 检查不改写已有有效比分，也不删除后台临时空比分；公示过滤由前端完成。测试在 `tmp/tests/` 临时目录创建独立数据，不修改实际比赛数据。

运行：`python -B -m unittest discover -s tests -v`。
