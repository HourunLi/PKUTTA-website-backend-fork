# `vibecoding/Logistics/Group-Ranking.md`

小组排名规则来源：胜一场积 1 分，负或弃权积 0 分；同积分者仅比较彼此比赛，依次取内部积分、局胜负比、球分胜负比，仍同分时抽签。

`backend/logic.py::group_standings` 实现这些步骤，以同一总积分的并列组为相互比赛范围；某一步分出部分名次后，仍并列的子集只用彼此间比赛从内部积分重新计算（ITTF 3.7.5.3）。比值精确比较，正数除零视为无穷、`0/0` 为零，弃权比分按零统计局与球分。每行保留实际参与的比较过程，重算时记录最内层的值，未参与字段为 `null`。后台保存排名及抽签排列，公开页直接展示；独立循环赛保留 revision 4 排名规则。
