# `vibecoding/revision-5.md`

第五轮修改需求：对阵矩阵整体和每个单元格均为正方形，完赛高亮覆盖整个单元格；主对角线下方可以查看、编辑对称场次，与上方位置共用同一比赛数据。出线名单和比赛结果的姓名、名称列统一为“选手”。

每个小组增加可在后台设置、前后台展示的预定时间和预定桌号。设置小组计划覆盖内部所有场次对应字段，修改内部场次实际时间、桌号不会反向修改小组计划。

页面控制代码和唯一数据库均放于 `webpage/`；后台直接增量修改该数据库，公开页按层级读取，无需生成公开副本或汇总索引。发布只需同步 `webpage/`，无需运行 build。公开展示过滤后台临时空比分，数据库仍保留供编辑。后续手机显示调整要求名单和对阵矩阵的标题、表格在宽度不超过 620 像素时居中。
