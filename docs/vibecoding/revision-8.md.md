# `vibecoding/revision-8.md`

本次需求统一独立循环赛与小组赛的展示和排名，并完善完赛结果、手机端宽表与原报名名单下载。

- 独立循环赛先展示无排名的选手表和对阵图；全部场次完赛后展示第三张排名依据表。采用小组赛相同的积分、同分内部积分、局胜负比、球分胜负比和抽签规则，排名与抽签顺序写入阶段数据库以保持刷新后稳定。仅实际参与比较的依据有内容，其他单元格留空并为灰色。
- 小组及循环赛三表共用 43px 表头和 46px 内容行，对阵列宽 56px。窄屏上下居中排列，选手表固定 220px；对阵图、排名表超出可用宽度时在各自容器内横向滚动，页面本身不随人数增加而变宽。没有排名表时，电脑端选手表和对阵图整体居中。
- 每个阶段全部完成后提供可收起的结果卡片。小组赛列出线名单，淘汰赛列前八名，循环赛列完整排名。结果表宽度至多 580px，居中显示；姓名居中且可点击查看详情。作为项目最终结果的淘汰赛和循环赛，仅前三名的名次单元格分别使用黄色、银色、棕色，小组出线名单不使用奖牌色。
- 项目第一个阶段下提供默认收起的“参赛名单”卡片，展开后以逗号分隔的段落展示原报名选手，点击名字可查看学院。标题右侧下载图标与展开箭头分别操作，点击下载不会切换卡片展开状态。CSV 使用 UTF-8 BOM、标准可导入表头和标准引号转义，按照项目形式保留原报名顺序、成员、队伍和种子级别；团体表头成员数量取最大报名队伍人数，每行保留实际成员。小组后淘汰赛的虚拟种子级别不替代原报名数据。

实现说明见 `backend/storage.py`、`webpage/app.js` 和 `webpage/style.css` 的镜像文档；新增排名及前端回归检查位于对应 `tests/` 文档。
