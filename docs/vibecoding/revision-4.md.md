# `vibecoding/revision-4.md`

第四轮规则修订要求：循环赛和小组赛依次比较胜场、获胜局和小分总和；三项全同者再只比较并列选手之间的比赛，仍无法区分时按姓名排序。CSV 种子级别允许 0 或正整数，数字越大优先级越高。

小组抽签先按非零种子级别降序，前“组数”名每组各放一人，其余选手随机填充。至少 8 人的淘汰赛将前四种子分别放进四个四分之一区的首场一号位，第 5 名至首轮场数名随机占其余一号位，剩余选手随机占二号位，空位轮空。小组赛出线者使用虚拟种子：总出线 `n` 人、共 `m` 组时，第 `g` 组第 `r` 名为 `n - (r - 1) × m - (g - 1)`。
