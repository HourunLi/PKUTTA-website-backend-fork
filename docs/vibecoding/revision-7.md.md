# `vibecoding/revision-7.md`

本次需求包括创建赛事时的可选自定义文件名、品牌与 favicon 图片、Submit 位置、固定顶栏、赛事范围内的选手场次搜索，以及网络延迟下的局部加载与缓存。

- 创建赛事始终展示文件名输入框，勾选“自定义文件名”后才启用；未勾选时后台自动生成。自定义文件名以小写字母开头，可含小写字母、数字与单个连字符，重复名不覆盖已有赛事。
- `vibecoding/Figure/icon.jpg` 原样复制到 `webpage/icon.jpg`，用于左上品牌及 favicon。顶栏固定在屏幕上方并带轻微阴影；预留对应高度避免遮住页面。移除右侧“赛事首页”链接，品牌仍返回首页。
- 管理页 Submit 移到右下角，保留运行中禁用和失败弹窗。
- 当前赛事的子页面可打开“搜索比赛场次”卡片，按成员姓名搜索该赛事所有项目、所有阶段的实际场次。结果为无左右边框的单列表格，展示项目·阶段、双方名称、完成状态与比分、时间桌号及裁判；未完成项高亮。
- 搜索及导航的等待状态放在对应内容块中，保留页面标题和导航。原始 JSON 和聚合详情使用 60 秒内存缓存，并去重并发读取；有效期内切换同一项目的阶段不重复请求。过期时保留原内容后更新，后台写入失效相关缓存并阻止旧请求回写。搜索并行读取项目且分块展示结果，部分加载失败不抹去已找到的场次。

对应实现说明见 `backend/storage.py`、`backend/server.py`、`webpage/index.html`、`webpage/app.js`、`webpage/style.css` 及 `webpage/icon.jpg` 的镜像文档。
