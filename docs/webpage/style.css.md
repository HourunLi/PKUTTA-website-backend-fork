# `webpage/style.css`

Shared responsive styles for the public and administrator views. The canonical asset is `webpage/style.css`; the local server also exposes it at `/assets/style.css`. Defines the site shell, competition/event cards, roster/matrix/standings tables, knockout bracket, dialogs and form controls.

The header stays fixed at the top with a restrained shadow and `z-index: 40`, below modal overlays (`50`). Its 72px desktop height and 64px mobile height are reserved by body padding, so page content remains visible. Scroll padding also accounts for the header. The supplied logo fits a 38px image box with `object-fit: contain`. Header search is a compact icon button. At widths up to 380px, only the brand image is shown, mode badges stay on one line, and body minimum width is removed to avoid overflow when scrollbars occupy viewport space. The admin Submit button floats at bottom right (22px desktop, 16px mobile), with a gray disabled busy state; toast messages sit above it.

Roster, matrix and standings tables share 43px headers and 46px content rows. Matrix columns remain 56px wide to fit `wo:wo`, and wide tables scroll inside their wrapper. Score controls fill the cell; finished backgrounds apply to the entire `td`. Roster names use one-line ellipsis. Group and independent round-robin cards arrange a 220px roster, a matrix at its natural width, and standings occupying the remaining width with horizontal scrolling and a 180px minimum. When standings are absent or hidden, `two-table-layout` centers the first two tables together on desktop. Unused ranking metrics are gray, and group qualifier name cells are highlighted. The 950px breakpoint stacks dense table layouts in a `minmax(0, 1fr)` track and centers their sections and titles. The zero track minimum prevents a large matrix's intrinsic width from expanding the mobile grid. Roster width remains 220px while the matrix and standings clamp their wrappers to the available width and scroll internally. Shrinkable panels, bodies, grids and wrappers prevent large participant counts from widening the page; horizontal overscroll remains inside table wrappers.

All completed-stage results use a centered `result-table-wrap` whose width is the smaller of 100% and 580px. Participant cells and their clickable names are centered, with long names allowed to wrap. Qualifier tables keep a 420px content minimum that can scroll within the wrapper on narrow screens. Final knockout and round-robin ranks use `medal-gold`, `medal-silver` and `medal-bronze` backgrounds only on their first three rank cells. Group qualifiers do not receive medal styling. Result cards and the default-collapsed participant list share native details summaries, a custom rotating chevron and accessible focus styling. The participant-list header keeps its download icon separate from the chevron; the body is a wrapping paragraph of comma-separated clickable names, rather than a one-column table.

Knockout cards display muted leaf slot numbers, right-angle connecting lines, wide score buttons for WO, a compact bronze fixture and expandable results. The stage layout can shrink while bracket overflow stays inside its own scroll container. Group plan headings wrap time, table and referee fields. Admin game rows contain paired score text inputs, save status and delete controls; they wrap on mobile. Modal field rows use equal shrinkable columns and consistent spacing. Disabled custom filename inputs have a muted background, and checkbox fields use compact native checkboxes.

Search dialogs use a flexible input beside a 40px icon button. Results form a single-column table with only horizontal separators. Each item has muted project/stage and status text, bold opponent names, wrapping time/table/referee information, and a soft brand background while unfinished. Loading, empty and error cards fit within their content section. Inline and block loading indicators use a small spinner; reduced-motion preferences disable its rotation. Page sections can show these local states while breadcrumbs, titles and navigation remain visible.
