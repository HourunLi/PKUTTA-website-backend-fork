# 淘汰赛抽签规则

**种子级别.** 每一位选手有一个种子级别 $t_i\in \mathbb{N}\cup\{-1\}$。若种子级别 $t_i > 0$，则该选手是一个种子选手。若种子级别 $t_i = 0$，则该选手是小组第一。若种子级别 $t_i = -1$，则该选手既不是小组第一，也不是种子选手。

小组赛出线结果确定后，设 $n_s$ 为该小组赛的种子数量。对于 $i \in n_s$，第 $i$ 组的小组第一是淘汰赛的 $i$ 号种子。种子级别为 $n_s + 1 - i$。其他选手的种子级别按上述规则设置。

**抽签规则.** 首先回忆对于一个 $d$ 轮的淘汰赛（$d\geq 3$），有 $2^{d - 1}$ 个第一轮比赛，因此有同样数量的一号位和二号位。对于 $i = 1, ..., d - 1$，整个比赛可以被分为 $2^{i}$ 个 $1 / 2^i$ 区。

接下来按照如下规则抽签：

1. 如果存在一号种子，那么它被放入上半区最上方比赛的一号位，即第 $1$ 个位置。
2. 如果存在二号种子，那么它被放入下半区最下方比赛的一号位，即第 $2^{d} - 1$ 个位置。
3. 对于 $i = 2, ..., d - 1$，令 $R$ 为最大的数（$2^{i - 1} + 1 \leq R < 2^{i}$）使得存在 $2^{i - 1}$ 到 $R$ 号种子。如果 $R$ 不存在，直接 break。给这些种子每一个随机抽取一个当前全空的 $1/2^{i}$ 区，将其放入该区一个随机第一轮比赛的一号位。
4. 将所有的非种子小组第一均匀随机抽入当前有空闲的一号位。
5. 设轮空数为 $b$（签位数减人数）。每场第一轮比赛至多一个轮空：依次给 1 号、2 号……种子，再按抽签顺序给非种子小组第一，在其所在比赛的二号位放置轮空；仍有剩余轮空时，随机选取空闲一号位，在其对面放置轮空。
6. 将其余选手按小组名次从高到低依次随机抽入剩余位置。来自同一小组的第 $k$ 名（$k \geq 2$）不得与该组已落位选手处于同一个 $1/2^{\lceil \log_2 k \rceil}$ 区：第二名与第一名分处不同半区，第三、四名与同组其他人分处不同四分之一区，依此类推。若无法满足，则逐级放宽到更大的区。
